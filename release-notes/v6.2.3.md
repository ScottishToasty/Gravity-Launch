# Gravity Launch v6.2.3 — iPhone Standalone Web App

- Added Apple standalone web-app metadata so a newly created iPhone Home Screen web app can launch without Safari navigation controls.
- Set the iPhone status-bar style to black, avoiding translucent status-bar overlap.
- Set the Home Screen app name to Gravity Launch.
- Kept viewport-fit=cover and all gameplay, physics, controls and canvas layout unchanged.
- Updated displayed version from v6.2.2 to v6.2.3.

## Install on iPhone

1. Publish the updated `index.html` to GitHub Pages.
2. Delete the old Gravity Launch Home Screen shortcut.
3. Open the published URL in Safari, tap Share → Add to Home Screen, and enable Open as Web App if offered.
4. Launch from the new Home Screen icon and check for the missing Safari toolbar and the full power bar.

If the power bar is still clipped, a separate responsive-height adjustment is needed.
